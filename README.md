shuffle shader Code and Video and have fun

made on Godot 4.6

made by juju

This program use GDShaders for more information read the docs 

https://docs.godotengine.org/en/stable/tutorials/shaders/shader_reference/shading_language.html

## Launch on Linux

```
chmod +x main.x86_64
./main.x86_64
#or
./main.sh
```

# Commandes

ALT + ENTER = Execute Code

ALT + F4 = Close Program

### Media Commandes

media are images & videos

Q = Lock Media

Backspace = Delette Media

mouse wheel = rotate / zoom

ALT = change mode  for mouse wheel

### import Media

GDVJ read only image sequence

choose a folder  who countain images sequence on format jpg or png
